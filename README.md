# MiddlePaste

一个 macOS 菜单栏小工具，把 Linux 上"选中即复制、中键粘贴"的习惯带到 Mac，顺带集成了几个常用的鼠标和触控板小功能。

本地编译、本地签名，不依赖任何第三方库，整个程序只有一个源文件。

## 功能

| 功能 | 说明 |
|---|---|
| 选中即复制 | 鼠标拖选文字，或双击、三击选词，自动复制 |
| 中键粘贴 | 鼠标中键在鼠标位置粘贴 |
| 复制文件路径 | Finder 里选中文件或文件夹，按中键或触控板双指连点，复制完整路径（多个文件每行一个） |
| 鼠标滚轮反转 | 只反转鼠标滚轮的方向，触控板不受影响 |
| 四指轻点 | 触控板四指轻点，打开"应用程序窗口"（App Exposé） |

几个细节：

- 点击或拖动空白处不会触发复制，也就不会有系统提示音。
- 系统截图框选时不碰剪贴板。
- 复制出来的不是文字（比如图片）时，会把原来的剪贴板内容放回去。
- Ghostty 终端默认放行，使用它自带的选中复制和中键粘贴。
- Finder 之外的软件里，右键没有任何延迟。

## 系统要求

- macOS 13 或更高（开机自启用到了 `SMAppService`）
- 命令行工具：在终端执行 `xcode-select --install`

## 安装

```bash
git clone https://github.com/Zalozheng/<仓库名>.git
cd <仓库名>/MiddlePaste
chmod +x build.sh
./build.sh
open MiddlePaste.app
```

`icon.png` 放在 `build.sh` 同一个文件夹里，会自动生成应用图标，没有就用默认图标。编译完成后，可以把 `MiddlePaste.app` 拖进"应用程序"文件夹。

## 授权

第一次运行需要这些权限：

| 权限 | 位置 | 用途 |
|---|---|---|
| 辅助功能 | 系统设置 → 隐私与安全性 → 辅助功能 | 监听鼠标事件、读取菜单状态、模拟按键 |
| 自动化（Finder） | 第一次在 Finder 里按中键时弹窗，点"好" | 读取选中文件的路径 |
| 输入监控 | 系统设置 → 隐私与安全性 → 输入监控 | 四指轻点读取触控板触点，没反应时再加 |

重新编译后授权失效的话，在列表里把 MiddlePaste 删掉，再重新添加。

## 触控板设置

Finder 里的双指连点需要：系统设置 → 触控板 → 光标与点按 → 辅助点按，选"用两指点按或点击"。

四指轻点需要系统自带的"应用程序窗口"手势保持默认快捷键（Control + ↓）。

## 菜单栏选项

- **启用：** 总开关
- **拖选文字自动复制：** 单独开关
- **Finder 里双指连点 = 复制路径：** 单独开关
- **鼠标滚轮反转（触控板不变）：** 单独开关
- **四指轻点 = 应用程序窗口：** 单独开关
- **开机自启：** 第一次运行时默认打开
- **隐藏菜单栏图标：** 隐藏后，在"应用程序"里再双击一次 MiddlePaste 即可恢复

## Ghostty 配置

Ghostty 用自带功能，在它的配置文件里加一行：

```
copy-on-select = clipboard
```

想让其他终端也放行，把它的 Bundle ID 加进 `main.swift` 里的 `nativeMiddleApps`。想让某个软件粘贴前不先点一下左键，加进 `noClickApps`。

## 工作原理

- **事件监听：** 用 `CGEventTap` 监听鼠标左键、右键、中键和滚轮事件。
- **选中即复制：** 拖选结束后，先检查前台软件菜单栏里"拷贝"是否可用。灰色说明没选中内容，就不按 Cmd+C。可用时让软件自己执行一次 Cmd+C，保证复制的是当前真正选中的内容。
- **中键粘贴：** 在鼠标位置先点一下左键让光标落位，再模拟 Cmd+V。终端类软件跳过这一下点击。
- **滚轮反转：** 触控板的滚动事件是"连续的"，普通滚轮不是，据此区分后只反转滚轮。
- **四指轻点：** 通过系统私有框架 `MultitouchSupport` 读取触点，判断"恰好 4 根手指、很快抬起、基本没移动"，然后模拟 Control + ↓。

## 已知限制

- 选中即复制会覆盖剪贴板里上一次 Cmd+C 的内容，不想要时在菜单里关掉。
- 个别软件（例如网页内核的编辑器）菜单状态更新较慢，偶尔会漏掉一次复制，再选一次即可。
- 在 Finder 里，单次右键或双指点按会延迟约 0.4 秒弹出菜单，因为要等第二下。
- 四指轻点依赖私有框架，系统大版本更新后可能失效。
- 偶尔遇到滚动卡顿时，先退出 MiddlePaste 再重新打开；仍然卡就在菜单里逐项关闭功能，定位是哪一项引起的。

## 卸载

1. 菜单栏图标 → 关闭"开机自启" → 退出
2. 删除 `MiddlePaste.app`
3. 在"辅助功能"和"输入监控"里移除 MiddlePaste
4. 清除设置（可选）：

```bash
defaults delete local.middlepaste
```
